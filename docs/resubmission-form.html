Correction implemented

AgentPay Firewall is now a two-sided Algorand x402 payment product. A Seller sets the USDC amount and receiving address, then creates a 7-day HMAC-signed checkout link. The Buyer reviews the exact terms before connecting Pera Wallet. Each link resolves to a dynamic @x402/express + @x402/avm resource whose PAYMENT-REQUIRED challenge must match the signed amount and recipient. GoPlausible handles verification and settlement.

How evaluators can verify it

1. Open https://agentpay-firewall.vercel.app/. 2. Set a payment title, USDC amount, and receiving Algorand Testnet address. 3. Click "Create payment link". 4. Open the generated Buyer checkout and review amount, recipient, network, and expiry. 5. Connect Pera Wallet only after the signed request is verified. 6. Run npm run smoke:checkout to verify live link creation, dynamic HTTP 402, AVM details, and tamper rejection.
